ReliabilityOptimization

ReliabilityOptimization provides reliability-based design optimization (RBDO/RBTO) on top of the Nonconvex ecosystem. A deterministic function f(x, p) of the design variables x and the random parameters p is wrapped into a RandomFunction, which returns the first-order Gaussian approximation of the output distribution, linearized at the most probable point (MPP). The reliability analysis is performed with

  • FORM first-order reliability methods:
    • RIA — the reliability index approach (Hasofer-Lind), and
    • PMA — the performance measure approach;
  • SORM — the second-order (Breitung curvature-corrected) method.

All first-order quantities — the RandomFunction output distribution, the reliability index, the performance measure and the probabilistic constraints — are differentiable with respect to the design variables.

This documentation is a fragment of the Nonconvex documentation and is also built standalone.

Quick start

julia> using ReliabilityOptimization, Distributions

julia> # a limit state with a random property p (margin convention: g ≥ 0 is safe)

julia> g = (x, p) -> x[1] + 2x[2] - p[1];

julia> p = MvNormal(zeros(1), ones(1, 1));

julia> β = reliability_index(g, [2.0, 1.0], p); # = 4

julia> pf = failure_probability(g, [2.0, 1.0], p); # = Φ(−4)

julia> p0 = getp0(g, [2.0, 1.0], p); # the MPP

julia> using Zygote

julia> Zygote.gradient(x -> reliability_index(g, x, p), [2.0, 1.0])[1];

Theory

The methods are reviewed in Theory: the limit-state formulation, standard normal space, the Hasofer-Lind reliability index, FORM (RIA and PMA) with its linearization and sensitivity analysis, and SORM's curvature correction, with references.

Reliability methods

FORM wraps a first-order method: RIA solves the Hasofer-Lind problem for the reliability index, PMA solves the inverse performance-measure problem, and SORM corrects the failure probability for limit-state curvature. See Reliability methods.

Random functions

RandomFunction turns a deterministic function with random parameters into a callable returning the linearized Gaussian output distribution, differentiable with respect to the design. See Random functions.

Distribution transformations

All reliability computations happen in standard normal space. Gaussian parameters use the exact affine transformation, univariate distributions use their Rosenblatt transformation (the classic textbook table: Normal, Lognormal, Uniform, Exponential, Gumbel, Weibull, Frechet, Gamma, ...), and correlated non-Gaussian parameters use the nataf_transform transformation. See Distribution transformations.

Probabilistic constraints

reliability_constraint builds constraints of the form P(g(x, p) ≥ 0) ≥ Φ(β_target) (margin convention: positive values safe) for Nonconvex models, in either the RIA or the PMA formulation. See Reliability constraints.

Conventions and limitations

  • The reliability index β is independent of which side of the limit state fails; the PMA performance measure and reliability_constraint use the margin convention (positive values safe, g = 0 the failure surface).
  • Limit states may be scalar- or vector-valued for RIA, but must be scalar-valued for PMA and SORM.
  • The output-distribution approximation is first-order. The default limit-state Jacobians are central finite differences; supply a jacobian function for better performance.
  • The inner reliability problems are solved with a Nonconvex optimizer (default: IpoptAlg); the inner VecModel and solver Workspace are built once per RandomFunction and reused with warm starts.
  • SORM indices are not differentiable, and the inner problem workspace is not thread-safe.
